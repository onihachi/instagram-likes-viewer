# いいねビュー — Instagram

Instagramの「いいね！」履歴を、広い一覧と大きな投稿表示で見やすくするChrome拡張です。

**[最新版ZIPをダウンロード](https://github.com/onihachi/instagram-likes-viewer/releases/latest)** · [導入手順](INSTALL.ja.md)

一覧のサムネイルサイズを調整し、投稿を開いて×・Escで閉じると、元の場所から続きを見られます。投稿はウィンドウサイズに自動フィットし、拡張の操作UIは閉じるボタンだけ。

Chrome Web Storeには未登録です。ZIPを展開して手動で読み込みます。Meta / Instagramの非公式拡張です。

Mac Chromeの公式いいね一覧を残したまま、クリックした公式投稿を別ウィンドウに大きく開く拡張です。右上の×・Escで閉じ、元の一覧の同じ位置へ戻ります。古い写真とカルーセルについて実Instagramで位置保持を確認しました。検証範囲は [QA記録](docs/QA.ja.md) を参照してください。

[導入手順](INSTALL.ja.md) に従い `extension/` をChromeに読み込みます。ビルドやAPIキーは不要です。更新・ページ再読み込みの後は、いいね一覧で拡張ボタンを押してONにしてください。

実際の一覧には投稿URLのアンカーがありませんでした。表示済みカードの画像URLに含まれる識別子を解析して公式投稿URLを開きます。連結された動画識別子はカードに表示された投稿日で候補を絞ります。一意に特定できないカードは一覧を維持して案内します。Instagramの構造変更によって使えなくなる可能性があります。

元の一覧DOMと読み込み済みの範囲を残します。追加読み込みは通常のスクロールに任せます。ページ再読み込みをまたぐ保存は行いません。実カードの別ウィンドウ表示には親タブの戻る・進むによる再表示機能はありません。従来のアンカー用iframe表示は互換処理として残しており、架空デモはその方式です。

権限は `activeTab` と `scripting` のみです。Cookie、ブラウザストレージ、非公開APIを読みません。履歴の外部送信や大量取得はありません。公式投稿ページの通常通信はInstagram自身が行います。[データの扱い](PRIVACY.ja.md)、[設計](docs/DESIGN.ja.md)。

## 開発用コマンド

```sh
npm ci --ignore-scripts
npm test
npm run check
python3 scripts/check-demo.py
npm run package
```

Node.js 22以降とPython 3を想定しています。jsdomは試験専用で配布拡張には入りません。`npm run demo` は架空投稿のデモです。

一覧は画面幅を使って並べます。左下のサムネイルスライダーで180〜460px相当の大きさを調整し、幅に応じて2〜8列を選びます。「元の一覧」で標準表示へ戻せます。設定はその起動中のみです。

投稿ウィンドウはウィンドウ寸法に合わせて自動拡大縮小します。拡張が追加する操作は閉じるボタンだけです。Escでも閉じられます。カルーセルの矢印や動画プレイヤーは保持します。通常の公式表示を使う場合は、一覧で拡張を停止してください。一覧のサムネイル調整は引き続き使えます。
